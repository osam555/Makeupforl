## 0. 결론

1. 6~10위는 **모두 쇼츠**이고, 1·2위와 같은 「질문 → 답변」 낭독 틀이다. 길이가 이미 60초 안팎이라 나누지 않고 **편당 쇼츠 1편**으로 다시 만든다.
2. 고칠 점은 1·2위와 같다. **결론이 늦고**(「질문… 답변… 네」 낭독에 5~12초), **같은 말을 두 번 하고**(⑦ 「어떤 스타일도 가능합니다」, ⑥ 「화려한 이미지도 좋습니다」), **끝이 자기 소개나 구독 부탁**이다(⑦·⑩).
3. **9위(`aNo9ghgG85Y`, 혼주헤어 앞머리 알려드려요)는 뺐다.** 비공개로 내려 둔 영상이고, 자막 트랙이 없어 대본을 읽을 수 없으며, 주제가 3위 리메이크(앞머리 3편)와 겹친다. 빈 자리는 **11위(`B5i9l9937uo`, 한복색깔 어때요?)** 로 채웠다. 비공개를 푼 뒤 다시 만들지는 사이트 매니저가 정한다(6절).
4. 원장님 얼굴·목소리를 AI로 만들지 않았다. 소리는 내레이터(Typecast Yunjeong, `voice.json`), 그림 속 사람은 뒷모습만이다.

## 3. 장면 순서

담채 화풍, 세로 9:16, 한 문장 = 한 컷, 편당 움직이는 컷 3개(나머지는 정지 그림에 느린 확대). 사람은 뒷모습만 그린다. 끝 화면은 다음 질문 + 「프로필 링크 → P?·??」 + 「3개월 이용권 55,000원」 + 「신청 · 전화 02-323-3321」. 「예약 시 차감」은 넣지 않았다.

| # | 컷 순서 (★ = 움직이는 컷) |
|---|---|
| ⑥ | ★넓은 예식장 로비의 뒷모습 → 색 고운 저고리 한 벌 → 화장대의 색조 팔레트 → 금빛 장식과 비단 → ★장식 꽂은 올림머리 뒷모습 → 컬러 저고리와 아이보리 저고리 → 한복 한 벌과 꽃신 → ★샹들리에 달린 넓은 홀 → 끝 화면 |
| ⑦ | ★짧은 커트 머리 뒷모습 → 빗과 핀 → 빗 두 개 → ★귀 옆에 장식을 단 짧은 머리 뒷모습 → 받침대 위 부분 가발 → 색이 같은 가발과 머리 타래 → ★거울 엎어 둔 화장대 → 끝 화면 |
| ⑧ | ★달력과 롤 → 굵은 웨이브 머리 타래 → 볼륨 있는 올림머리 뒷모습 → 달력 → ★풀린 웨이브 타래 → 달력의 두 표시 → 염색 그릇과 솔 → ★굵은 롤 → 끝 화면 |
| ⑩ | ★아이보리 저고리 여러 벌이 걸린 한복집 → 아이보리 저고리와 치마 두 색 → 똑같은 저고리 세 벌 → 아이보리 천과 탁한 살구빛 천 → ★화장대의 화장품과 저고리 → 색색의 저고리 원단 → ★한복집 진열대 → 끝 화면 |
| ⑪ | ★하얀 저고리 한 벌 → 붉은 치마와 푸른 치마 → 하얀 저고리 여러 벌 → 저고리의 자수 → ★색색의 치마 원단 → ★하얀 저고리와 노란 치마 한 벌(예식장 창가) → 노란 치마 주름 → 끝 화면 |

- 사람 컷은 기준 그림(분홍 저고리·자주 치마)에 맞춰 그리므로, ⑩·⑪처럼 저고리 색이 주제인 편은 **옷만 그린 컷**으로 채웠다.

만든 뒤의 편별 길이·음량·받아쓰기 대조 결과는 만든 세션의 보고에 적는다. 문서에는 방법만 남긴다.
