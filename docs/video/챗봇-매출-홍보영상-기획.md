# 홍보영상 기획 — 「매출 나오는 챗봇 홈페이지」

> 2026-11-02. 챗봇이 100문100답 첫 유료 이용자를 만들어 낸 것을 계기로,
> **"홈페이지가 손님과 대화하고, 그 대화가 결제로 이어진다"** 를 보여 주는 영상.
> 원장님 얼굴은 `docs/video/README.md` 1절 규칙대로 **실제 촬영본만** 쓴다.
> 그 밖의 모든 화면(채팅 말풍선·사이트 화면·숫자)은 HyperFrames 로 그린다 — 실제 사이트 화면이라 AI 생성의 일관성 문제가 없다.

## 0. 먼저 채워야 할 사실 (빈칸은 영상에 넣지 않는다)

| 항목 | 값 | 어디서 확인 |
|---|---|---|
| 챗봇이 어디에 떠 있나 (사이트 우하단 / 카카오채널 / 인스타 DM) | **미확인** | 챗봇 운영 화면 |
| 유료 전환 건수와 기간 (예: 10/20~11/1, 3건) | **미확인** | `site_config/wed100` 의 `members[]` 날짜 |
| 손님이 챗봇에 실제로 물은 질문 (익명화해서 2~3개) | **미확인** | 챗봇 대화 기록 — 손님 식별 정보는 쓰지 않는다 |
| 결제까지 걸린 시간 (첫 대화 → 결제) | **미확인** | 대화 기록 + members `until` 역산 |
| 이용권 | 3개월 55,000원 | `src/lib/wed100Access.ts` (확정) |
| 전화 | 02-323-3321 | 사이트 (확정) |

**숫자는 사실 그대로만 쓴다.** "매출 N배" 같은 비교 표현은 근거 수치가 없으면 뺀다.
건수가 작아도 괜찮다 — 이 영상의 설득 포인트는 규모가 아니라 **"사람이 안 붙어 있어도 팔린다"** 다.

## 1. 누구에게, 무엇을 말하나

- **1차 시청자**: 원장님과 같은 처지의 샵·전문직 자영업자(홈페이지는 있는데 문의가 안 오는 사람). 사이트 매니저 포트폴리오 겸.
- **2차 시청자**: 혼주 손님 — "밤에 물어봐도 답해 주는 곳" 이라는 인상.
- **한 줄 메시지**: *홈페이지가 상담하고, 상담이 결제가 됐다.*
- **톤**: 자랑이 아니라 **기록**. "이런 일이 있었다" 를 화면 증거로 보여 준다.

## 3. 쇼츠 A 구성안 (40초)

화면은 전부 HyperFrames(HTML/CSS 타임라인 → mp4). 챗봇 대화는 **실제 대화를 익명화한 재구성**이고, 자막으로 그렇게 밝힌다.

| 시각 | 화면 | 자막(큰 글씨) | 소리 |
|---|---|---|---|
| 0:00~0:03 | 검은 화면, 폰 시계 **23:47** 만 떠 있음 | 밤 열한 시 사십칠 분 | 조용한 알림음 한 번 |
| 0:03~0:10 | 챗봇 말풍선이 타이핑되며 뜬다 — 손님: "어머니 한복이 자주색인데 메이크업 톤을 어떻게…" | 손님이 홈페이지에 물었다 | 타이핑 소리 |
| 0:10~0:17 | 봇 답변 말풍선 (100문100답 무료 문항 요약) + 아래 "자세한 답은 100문100답에서" 카드 | 사람은 자고 있었다 | 받침 음악 시작 |
| 0:17~0:24 | 카드를 누르면 `/honjoo100` 잠긴 문항 화면 → 이용권 55,000원 단추 | 3개월 55,000원 | |
| 0:24~0:29 | **결제 완료** 화면(실제 화면 캡처를 마스킹) → 어드민 `members[]` 에 한 줄 추가되는 모션 | 결제 완료 — 00:0N (사실 시각) | 짧은 '띵' |
| 0:29~0:35 | 숫자 카드: **N건 / 기간** (사실만) | 사람이 안 붙어 있어도 팔렸다 | |
| 0:35~0:45 | 원장님 실제 촬영(정면, 가슴 위) 한 마디 + 끝 카드 | "25년 상담을 홈페이지에 넣었어요" | 원장님 목소리 |
| 끝 카드 | 메이크업포엘 · 대표원장 김성희 · makeupforl.co.kr · 02-323-3321 | | |

원장님 대사 후보(원장님 말투로 고쳐 쓰심):
- "제가 25년 동안 상담실에서 드리던 말을 홈페이지에 넣어 뒀어요. 밤에 물어보셔도 답이 나옵니다."
- "이제 전화 안 하셔도 돼요. 홈페이지에 물어보세요."

## 4. 만드는 순서 (비용 ≈ 0, 다른 맥에서)

1. **사실 수집** — 0절 표를 채운다. 대화 기록은 이름·연락처·날짜 중 식별되는 부분을 지운다.
2. **화면 캡처** — Playwright 로 실제 사이트를 1080×1920 으로 찍는다:
   `/`, `/honjoo100`, 잠긴 문항 하나, 결제 안내, 어드민 회원 목록(이메일은 가린 뒤). 이 캡처를 HyperFrames 장면의 배경으로 쓴다.
3. **HyperFrames 장면 제작** — 장면마다 HTML 한 장:
   - `01-clock.html` 시계
   - `02-chat.html` 말풍선 타이핑 애니메이션(CSS keyframes, 글자 단위)
   - `03-paywall.html` 캡처 위에 손가락 탭 하이라이트
   - `04-paid.html` 결제 완료 + 목록 한 줄 슬라이드인
   - `05-number.html` 숫자 카운트업
   - 공통 자막 컴포넌트: 하단 1/4, 흰 글씨 + 검은 스트로크, 컷 경계 0.26초 페이드(`book/promo/영상제작-규칙.md` 6절과 동일)
4. **원장님 촬영** — `docs/video/README.md` 4절 안내대로 폰 세로 촬영, 대사 2개를 각각 3번씩. 받아쓰기(whisper) 로 가장 잘 말한 테이크를 고른다.
5. **합치기** — ffmpeg: 장면 mp4 이어붙이기 → 원장님 컷 → 끝 카드. 음량 −14 LUFS, 1.5초 넘는 무음 없음.
6. **검수** — 숫자·시각이 0절 표와 일치하는지, 손님 식별 정보가 없는지, 과장 표현("최고", "N배")이 없는지.
7. **결재** — `/admin/proposals` 에 요청으로 올려 원장님 확인 뒤 원장님 계정으로 업로드.

```
video/
  scripts/챗봇-쇼츠A.md        대사·자막 최종본 — 커밋
  work/chatbot/*.html          HyperFrames 장면 — 커밋(화면 캡처 png 는 제외)
  raw/                         원장님 촬영 원본 — 커밋 안 함
  out/챗봇-쇼츠A.mp4           완성본 — 커밋 안 함
```

## 5. 지킬 것

- 손님 대화는 **익명화·재구성**이고 자막에 "실제 상담을 바탕으로 재구성" 을 넣는다. 손님 이름·연락처·결제 수단은 어떤 형태로도 화면에 내지 않는다(개인정보처리방침과 같은 기준).
- 숫자는 0절 표에서 확인된 것만. 비교·과장 표현 금지.
- 원장님 얼굴·목소리는 실제 촬영본만. 시술 효과 언급 없음(메이크업 정보 영상이 아니라 운영 이야기이므로 애초에 필요 없다).
- 결제 화면은 PG 사 로고·카드 정보가 보이면 마스킹한다.
