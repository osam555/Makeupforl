# 홍보영상 기획 — 「매출 나오는 챗봇 홈페이지」

> 2026-11-02. **파는 것은 Oilpage**(사업자용 홈페이지 + 24시간 챗봇 + 사장 대시보드, 데모 https://youngliving.page).
> **증거는 메이크업포엘** — 챗봇이 100문100답 3개월 이용권(55,000원) 유료 이용자를 만들어 냈다.
> Oilpage 쪽 기존 영상 틀(`oilpage/docs/plan/aroma-oil-promo-video-plan.md`: HyperFrames · Typecast 지선 · 실화면 녹화)을 그대로 쓰고,

## 0. 먼저 채워야 할 사실 (빈칸은 영상에 넣지 않는다)

**숫자는 사실만.** "매출 N배" 같은 비교 표현은 근거 수치가 없으면 뺀다. 건수가 작아도 괜찮다 —
이 영상의 설득 포인트는 규모가 아니라 **"사람이 안 붙어 있어도 팔렸다"** 다.

## 1. 누구에게, 무엇을

- **시청자**: 홈페이지는 있는데 문의가 안 오는 소규모 사업자(오일 판매·클래스·샵·전문직). Oilpage 가입 유도.
- **한 줄**: *홈페이지가 상담했고, 상담이 결제가 됐다.*
- **톤**: 자랑이 아니라 **기록**. 실제 화면 캡처와 실제 숫자로만 말한다.
- **차별점 한 줄**(Oilpage 계획 §0-C 그대로): 본사 채팅은 주문·계정, 사장님 챗봇은 사용법·상담 → 그리고 **결제까지**.

## 3. 쇼츠 A 장면표 (45초)

챗봇 화면은 youngliving.page 위젯 모양(초록 머리띠 「오일 챗봇 · 24시간 · 밤에도 답해요」, 병 모양 봇 아바타, 아래 미리 정한 질문 칩 4개, "제품 라벨·공개 자료 범위에서만 답합니다" 꼬리말)을 **메이크업포엘 색으로 바꾼 같은 레이아웃**으로 HyperFrames 에서 그린다. 대화는 실제 로그를 익명화한 재구성이고 자막으로 그렇게 밝힌다.

| 시각 | 화면 | 자막(큰 글씨) | 내레이션(지선) |
|---|---|---|---|
| 0:00–0:03 | 검은 화면, 폰 시계 **23:47** | 밤 11시 47분 | (없음, 알림음 한 번) |
| 0:03–0:10 | 위젯 열림 → 손님 말풍선 타이핑: "어머니 한복이 자주색인데 메이크업 톤을 어떻게…" (실제 질문으로 교체) | 손님이 홈페이지에 물었다 | 사장님이 자는 시간에, 손님이 홈페이지에 물었습니다. |
| 0:10–0:17 | 봇 답변 말풍선(짧은 3줄 + 「자세히」) + 아래 카드 「이 질문의 전체 답 → 100문100답」 | 사람은 자고 있었다 | 챗봇이 자료 범위 안에서 답하고, 전체 답이 있는 곳을 알려 줍니다. |
| 0:17–0:24 | `/honjoo100` 잠긴 문항 → 「이용권 구매 55,000원」 단추 탭 하이라이트 | 3개월 55,000원 | 거기엔 원장님이 25년 상담에서 가장 많이 받은 질문의 답이 있습니다. |

## 4. 본편에 붙는 60초 (Oilpage 장면표 앞)

기존 Oilpage 본편은 1번 "사장님, 같은 질문 오늘 몇 번 답하셨나요?" 로 시작한다. 그 앞에 쇼츠 A 의 0:03–0:35 를 16:9 로 다시 조립해 **"먼저 결과부터"** 로 보여 주고, 원장님 15초 → "그래서 어떻게 만드냐면" → 기존 1번으로 넘어간다. 끝의 요금 카드(무료 / 9,900원)와 엔드카드는 기존 그대로.

## 5. 만드는 순서 (Oilpage 틀 재사용, 비용 ≈ 0)

작업 폴더는 Oilpage 계획과 같은 `~/dev/aroma-chatbot-promo/`(build/gen.mjs·assets/fonts·audio/ 재사용).

1. **사실 수집** — 0절 표. 로그에서 질문 본문만 뽑고 식별값은 지운다.
2. **실화면 녹화** — Playwright 1080×1920:
   - makeupforl: `/honjoo100`, 잠긴 문항 1개, 이용권 안내, 어드민 회원 목록(이메일 가린 뒤)
   - youngliving.page: 위젯 열기 → "몇 방울?" → 답 (챗봇 레이아웃 참고용 + 엔드카드 데모 컷)
3. **HyperFrames 장면** — HTML 한 장씩:
   `01-clock` 시계 · `02-chat` 말풍선 글자 단위 타이핑(위젯 레이아웃 복제) · `03-paywall` 캡처 위 탭 하이라이트 · `04-paid` 결제 완료 + 목록 한 줄 · `05-number` 카운트업 · `06-end` 엔드카드.
   자막 공통: 하단 1/4, 흰 글씨 + 검은 스트로크, 컷 경계 0.26초 페이드(`book/promo/영상제작-규칙.md` §6).
4. **내레이션** — 7줄 Typecast 지선(기존 캐시 `hook_tts.typecast` 재사용). 24kHz/48kbps/모노.
5. **원장님 촬영** — `docs/video/README.md` §4 안내. whisper 로 받아써서 가장 잘 말한 테이크.
6. **합치기** — ffmpeg: 장면 → 원장님 컷 → 엔드카드. −14 LUFS, 1.5초 넘는 무음 없음.
7. **검수** — 숫자·시각이 0절과 일치 / 손님 식별 정보 없음 / 과장 표현 없음 / 영리빙 로고·제품 사진 미사용(Oilpage 규칙).
8. **결재** — `/admin/proposals` 에 요청으로 → 원장님 확인 → 업로드(대충영어 채널은 사이트 매니저, 원장님 채널 올릴 땐 원장님 계정).

```
video/
  scripts/챗봇-쇼츠A.md        대사·자막·내레이션 최종본 — 커밋
  work/chatbot/*.html          HyperFrames 장면 — 커밋(캡처 png 제외)
  raw/                         원장님 촬영 원본 — 커밋 안 함
  out/챗봇-쇼츠A.mp4           완성본 — 커밋 안 함
```

## 6. 지킬 것

- 손님 대화는 **익명화·재구성**, 자막에 "실제 상담을 바탕으로 재구성". 이름·연락처·결제수단은 어떤 형태로도 안 보인다(메이크업포엘 개인정보처리방침·Oilpage 개인정보 차단 규칙과 같은 기준).
- 숫자는 0절에서 확인된 것만. 비교·과장 표현 금지. Oilpage 금칙어(치료·효능 등)는 이 영상엔 애초에 나올 일이 없지만 자막도 검사기를 통과시킨다.
- 원장님 얼굴·목소리는 실제 촬영본만.
- 결제 화면은 PG 로고·카드 정보 마스킹.
