## 0. 결론

1. 상위 5편은 모두 **혼주가 실제로 묻는 질문 하나에 쓸모 있는 답을 끝까지 준다.** 화면에는 **실제 한복 입은 혼주의 실제 머리**가 나온다.
2. 100문100답 v1/v2 쇼츠는 이 두 가지가 모자란다. 답을 결론 앞에서 끊고, 그림이 AI 소품 컷이다. 주제가 같아도(귀걸이, 올림머리, 염색·파마) 상위 20에 없다. 게시 기간이 짧은 탓도 있지만 형식 차이가 더 크다고 본다.
3. 원본 대본에는 고칠 점이 뚜렷하다. **결론이 늦고**(②), **군말과 근황이 길고**(③ 마지막 1분 30초), **번호가 틀리고 시간 순서가 뒤섞이고**(⑤), **남의 사진(구글 검색)을 썼다**(④). 내용은 그대로 두고 순서·길이·첫 문장만 바꾸면 더 낫다.
4. 리메이크 원칙: **원본이 이미 공개한 내용만, 순서와 말을 다듬어, 끝까지 들려준다. 100문100답은 그 다음 질문으로 잇는다.**
5. 다듬은 대본은 문장이 원본과 달라지므로 **원장님이 새로 읽어 녹음**하는 것이 기본이다(3-2). 녹음 전에는 원본 음성에서 문장이 같은 구간만 자른다.
6. 먼저 만들 편으로 **⑤ 안내사항 연작** 또는 **① 귀걸이**를 권한다(6절).

## 2. 왜 잘 됐나

1. **검색되는 질문 그대로가 제목이다.** 날짜가 잡힌 사람이 실제로 치는 말이라 2023~2025년 게시분이 지금도 조회를 모은다.
2. **첫 문장이 질문이다.** 쇼츠 두 편은 0초에 「질문」으로 시작한다.
3. **답이 끝까지 있다.** 「정리해 보면」이나 금지 사항으로 닫는다. 보고 나면 하나는 얻는다.
4. **실제 혼주가 보인다.** 메이크업은 결과물을 보고 고른다.
5. **말투가 상담실이다.** 「참 우리 혼주님들 공통점이 있어요」「해맑게 웃는 혼주님도 계신데」 같은 실제 사례가 믿음을 만든다. → 업그레이드 때 **이 말투와 사례는 남긴다.**

## 3. 업그레이드 방식

### 3-1. 원본 대본 검토 기준

편마다 원본 자동 자막을 시각과 함께 읽고 아래 여섯 가지를 본다. 4절의 「검토」 표가 그 결과다.

| 보는 것 | 고치는 방향 |
|---|---|
| 결론이 몇 초에 나오나 | 쇼츠는 **3초 안에 결론이나 반전**. 이유는 그 뒤 |
| 군말(인사, 「안내드리겠습니다」, 라벨 낭독) | 지운다. 원장님 소개는 끝 카드 글자로 |
| 오래 못 가는 말(계절 근황, 「영상 자주 못 올려요」) | 지운다. 영상 수명을 줄인다 |
| 순서·번호 오류 | 시간 순, 중요도 순으로 다시 세운다 |
| 꼬인 문장, 자동 자막 오인식 | 한 문장 한 뜻으로 푼다. 「메이크업포엘」「혼주」「가르마」 표기 통일 |
| 남의 자료(검색 사진 등) | 뺀다. 원장님 실제 결과물로 바꾼다 |

**내용은 바꾸지 않는다.** 원본에 없는 사실(귀걸이 대여, 여름 스타킹 등)을 새로 넣지 않는다. 필요하면 원장님께 답을 받은 뒤 넣는다. 아래 업그레이드 대본은 모두 원본 문장의 뜻을 순서·길이·말투만 바꿔 옮긴 것이다.

### 3-2. 소리를 어떻게 만드나

| 우선 | 방법 | 쓰는 때 |
|---|---|---|
| 1 | **원장님이 업그레이드 대본을 새로 읽는다**(`README.md` 4절 촬영 안내: 세로, 창 마주 보기, 핀마이크, 프롬프터) | 기본. 한 번 앉아서 다섯 편 대본을 다 읽으면 20분 안팎 |
| 2 | 원본 음성에서 문장이 같은 구간만 자르고, 새 문장은 **화면 글자로만** | 녹음 전 시험판 |
| 3 | Typecast 내레이터(`video/scripts/i2v/voice.json`) | ①②의 원래 낭독이 원장님이 아닌 내레이터였을 때만(9절 확인). 원장님 목소리를 AI로 만들거나 복제하지 않는다 |

음원은 PCM 24-bit 48kHz 모노로 작업, 최종 −14 LUFS, 1.5초 넘는 무음 없음. 자막은 자동 자막을 쓰지 않는다: whisper 받아쓰기 → 대본과 대조 → `align_voice.py` 로 시각 정렬.

### 3-3. 공통 규칙

| 항목 | 정한 것 |
|---|---|
| 유료 답 보호 | 대본은 **원본 영상의 내용만**. 시드(`src/data/wed100.json`)의 잠긴 답 글은 옮기지 않는다. 잇는 문항은 **제목과 목록 번호만** 말한다. 대본을 확정하기 전에 잇는 문항의 답이 이 쇼츠보다 더 주는 것이 있는지 확인한다 — 같으면 다른 문항으로 잇는다 |
| 끝 | 잠금 화면 대신 **다음 질문 한 줄**: 「프로필 링크 → 100문100답 P?·??」. 쇼츠 화면에선 링크가 안 눌려서 목록 번호를 말한다(`wed100-shorts-i2v-plan.md` 9-6) |
| 금지 문구 | 「메이크업 예약 시 차감」을 넣지 않는다 |
| 화면 | 원본 쇼츠의 **큰 질문 글자 + 혼주 뒷모습** 틀을 잇는다. 9:16 1080×1920. 원재료는 ① 채널 원본 ② 원장님 새 촬영 ③ 얼굴 없는 AI 소품 컷(빈 자리만) |
| 원본 파일 | Studio 다운로드가 화질이 좋다. 지금은 다른 세션이 Studio에서 작업 중이라 **받기를 미룬다.** 받기는 사이트 매니저가 하거나 지시할 때 |
| 손님 사진 | 원본 속 실제 혼주 사진을 새 영상에 다시 쓰기 전에 원장님께 동의 범위를 확인. 확인 전엔 뒷모습만 |
| 원본 영상 | 지우거나 제목을 바꾸지 않는다(검색 순위가 걸려 있다). 리메이크 설명란에 원본 링크를 건다 |
| 업로드 | 일부 공개 → 공개 전환은 사이트 매니저가 정한다. AI 컷을 쓴 편만 「합성 콘텐츠 — 예」 |

## 6. 만드는 순서 제안

1. **⑤ 안내사항 5-1·5-3** — 원본 음성 그대로 잘라도 대본과 뜻이 거의 같아 녹음 전에도 만들 수 있다. 「D-며칠」 시청자는 사기 직전의 사람이다.
2. **① 귀걸이** — 조회 1위 주제. 원장님 손 한 컷 + 대본 녹음 45초면 된다.
3. **③ 앞머리 3편** — 원장님 출연분 자르기라 talking-head 키트 첫 시험으로 맞다. 댓글 수요가 가장 크다.
4. **④ 올림머리**, **② 속옷** — 손님 사진 동의, 원장님 녹음을 받은 뒤.

한 편을 먼저 일부 공개로 올려 7일 지표(평균 시청 지속률, `?from=yt` 방문)를 본 뒤 나머지를 만든다. 원장님 녹음은 대본 열두 편을 한 번에 받는다(약 20분).

## 7. 비용·시간 (추정)

- 원본 자르기와 원장님 녹음 위주라 생성 비용이 작다. 편당 Flow 0~20크레딧(소품 컷 i2v 0~2개). Typecast는 3-2의 경우만.
- 원장님 부탁: 대본 녹음 1회(약 20분), 귀걸이 손 컷 1개, 사진 동의 확인, 댓글 질문 답(②덧붙임).

## 8. 지킬 것

- 원장님 얼굴·목소리를 AI로 새로 만들지 않는다. 원본을 자르고 꾸미거나 원장님이 새로 읽는다.
- 업그레이드는 순서·길이·말을 바꾸는 것이다. 원본에 없는 사실을 넣지 않는다.
- 100문100답의 잠긴 답 글을 옮기지 않는다. 연결은 문항 제목과 목록 번호만.
- 「메이크업 예약 시 차감」 문구를 넣지 않는다.
- 원본 영상의 남의 자료(④의 구글 검색 사진)는 리메이크에 쓰지 않는다.
- 원본 영상은 지우지도, 제목을 바꾸지도 않는다.
- 업로드는 일부 공개, 공개 전환은 사이트 매니저가 정한다. 업로드·Studio 작업은 지시가 있을 때만, 원장님 채널에만.
