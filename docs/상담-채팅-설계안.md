# 채팅형 상담 도우미 — 설계안 (초안, 2026-10-30)

광고 랜딩(star-event.net, xand2 랜딩 에디터)의 "말풍선 문답 → 연락처 수집" 흐름을 보고,
우리 사이트에 맞게 고친 안. 아직 코드는 없다. 원장님 결재 전 검토용.

## 지금 상태

- `/consultation`, `/reservation` 에는 전화(`tel:02-323-3321`)와 카카오톡 채널 링크만 있다.
- 손님은 "무엇을 물어봐야 할지" 모른 채 전화를 걸거나 카톡을 연다. 첫 마디가 어렵다.

## 무엇을 가져오고 무엇을 버리나

| 광고 랜딩 | 우리 안 |
|---|---|
| 말풍선이 하나씩 나오는 단계형 문답 | **가져온다** — 한 화면에 질문 하나, 탭 한 번 |
| 이름·나이·전화번호를 받아 서버에 저장 | **버린다** — 개인정보를 받지 않는다 |
| "오늘 자정까지만", 매달 자동 갱신되는 이벤트 기간 | **버린다** — 원장님 브랜드와 안 맞고 표시광고법 위험 |
| 들어오기만 해도 전환으로 잡는 gtag | **버린다** — 단계별 익명 카운트만 |

개인정보를 받지 않는 이유: `/api/track` 은 사람을 식별하지 않는 것이 원칙이고
개인정보처리방침도 그렇게 적혀 있다. 연락처를 받기 시작하면 방침 개정·보관 기간·파기 절차가
함께 따라온다. 연락은 손님이 카카오톡/전화로 직접 하게 두면 이 짐이 전부 사라진다.

## 흐름 (5단계, 30초 안)

1. **누구세요?** — 혼주(신랑 어머님 / 신부 어머님) · 신부 · 그 밖의 행사
2. **언제예요?** — 한 달 안 · 1~3개월 · 3개월 넘게 · 아직 미정
3. **가장 걱정되는 것** (여러 개 고름) — 올림머리 · 정수리 숱 · 중년 피부 · 한복 색 · 안경/흉터 · 사돈과 맞추기
   (`/consultation` 의 HELPS 9개 중 많이 묻는 것만)
4. **도우미의 답** — 고른 걱정마다 원장님 한 줄 처방 + 관련 칼럼/100문100답 무료 문항 링크
   (예: 정수리 숱 → 무료 문항 하나로 바로 연결 → 유료 상품으로 이어지는 길)
5. **상담 이어가기**
   - [카카오톡으로 보내기] — 고른 내용을 정리한 문장을 클립보드에 복사한 뒤 채널을 연다.
     "붙여넣기만 하시면 됩니다" 안내. 카톡 채널은 미리 채운 메시지를 받지 못해서 이 방법을 쓴다.
   - [전화하기] — `tel:` 링크, 영업시간이면 강조

복사되는 문장 예:
> 안녕하세요, 신랑 어머니입니다. 결혼식은 1~3개월 뒤이고, 올림머리와 정수리 숱이 걱정됩니다. 사전컨설팅 문의드려요.

## 화면

- 위치: `/consultation` 본문 위, 그리고 손님 화면 오른쪽 아래 떠 있는 단추("상담 도우미").
- 손님용이라 `SiteShell` 안에 들어가고 `mfl-original.css` 와 겹친다. 컴포넌트 안에서 클래스를 좁게 잡는다.
- 연출은 광고 랜딩처럼 말풍선 페이드인(0.4초) + "입력 중…" 점 세 개 정도만. 중년 손님 기준으로 글자 18px 이상, 단추 48px 이상.
- 원장님 사진을 말풍선 머리에 둔다(실제 사진만, AI 얼굴 생성 금지 — 영상 규칙과 같음).

## 데이터

- 질문·선택지·처방 문장은 `src/data/consult-chat.json` 시드 + Firestore `site_config/consult-chat` (wed100 과 같은 Firestore 우선·시드 폴백).
- 문장 변경은 `/admin/proposals` 결재로 올린다(`config` 종류라 승인 즉시 반영).
- 통계: `/api/track` 날짜별 문서에 증가값만 — `consultChat.open`, `step1`~`step4`, `kakao`, `tel`. 선택 내용은 **조합이 아니라 항목별 합계**만 센다(조합은 사람을 좁혀 갈 수 있음).
- 어드민 방문 통계에 "도우미 → 카톡/전화" 깔때기 한 줄 추가.
