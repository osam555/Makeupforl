# 혼주메이크업 100문 100답 — 서비스 기획서

**버전**: v1.0 (2026-08-05) · **작성**: Claude + 오쌤
**서비스 주체**: 메이크업포엘 (대표원장 김성희) · makeupforl.vercel.app

## 1. 서비스 개요

### 1.1 한 줄 정의
25년간 1만 명의 혼주를 만난 원장의 노하우 105문답을 **글 + 이미지 + 팟캐스트 음성 + 한/영 자막**으로 제공하는 콘텐츠 마케팅 서비스. 기존 메이크업포엘 홈페이지의 서브 메뉴로 운영한다.

### 1.2 왜 만드는가
| 문제 | 해결 |
|---|---|
| 혼주 고객은 상담 전 정보가 없어 '공장식' 업체에 실패 경험을 함 | 예약→당일까지 전 과정을 105문답으로 사전 교육 |
| 홈페이지 방문자가 신뢰를 형성할 콘텐츠가 부족 | 원장의 육성(팟캐스트)과 전문 지식으로 방문 전에 신뢰 구축 |
| '혼주메이크업' 검색 수요 대비 잡을 랜딩 페이지가 없음 | 질문 1개 = URL 1개, 105개의 검색 롱테일 랜딩 확보 |
| 5060 고객은 긴 글 읽기가 부담 | 듣는 콘텐츠(TTS 팟캐스트) + 큰 자막 |

### 1.3 타깃
- **1차**: 자녀 결혼을 3~6개월 앞둔 50~60대 혼주(주로 어머니). 네이버 검색·자녀의 공유로 유입
- **2차**: 부모님 대신 검색하는 30대 신랑·신부 (모바일, 공유 중심)
- **3차(확장)**: 해외 거주 한인·국제결혼 가정 (영어 자막 → 향후 다국어 콘텐츠)

### 1.4 핵심 지표 (KPI)
- 105문 페이지 검색 유입 (월간)
- 음성 재생 수 · 완청률
- 상담 CTA 클릭 → 1:1 사전컨설팅 예약 전환율

## 3. 핵심 화면 설계

### 3.1 목록 (/wed100)
- 히어로: 제목·부제("결혼식 날, 후회하면 늦습니다")·저자·[1번부터 이어듣기]·[1:1 사전컨설팅 예약] CTA·핵심 수치(105문/6파트/오디오 분량/한·EN 자막)
- 파트 카드 6개 (준비 순서대로) → 필터 연동
- 검색(질문·키워드·영문) + 파트 칩 필터 + 카드/목록 뷰 전환
- 질문 카드: 썸네일(1:1)·파트 배지·질문·키워드 태그·재생시간
- 하단 상담 전환 섹션

### 3.2 상세 플레이어 (/wed100/[slug]) — 서비스의 심장
- **이미지 무대(16:9)** + **영상 하단 자막**: 한국어 / English / 한+영 토글
- 2인 팟캐스트: 진행자(남, InJoon)가 질문 → 원장님(여, SunHi)이 답변. 화자 배지 표시
- 컨트롤: 재생/일시정지, ±10초, 진행바 시킹, 배속(0.8/1.0/1.25/1.5×), 반복
- 우측 스크립트: 현재 문장 하이라이트 + 자동 스크롤, 문장 클릭 시 해당 지점 재생
- 음성 미생성 항목은 "자막 읽기 모드"로 동작 (추정 타임라인)
- 하단: 답변 전문(SEO 본문), FAQ JSON-LD, 이전/다음, 같은 파트 관련 질문 4개
- CTA: "이 내용으로 상담 예약" (클릭 이벤트 적재)

### 3.3 어드민 (/admin/wed100) — 콘텐츠를 원장이 직접 수정
- 좌측: 105문 리스트(검색/파트 필터/음성·공개 상태 점)
- 우측 편집: 질문(한/영), 답변 본문(문단), 자막 큐 표(한/영 인라인 편집), 대표 이미지 URL(사진 교체 가능, 비우면 자동 SVG), 공개/비공개
- [본문에서 큐 재생성]: 문장 자동 분할 → 영문·타임코드 초기화 → TTS 재생성 필요 표시
- [DB에 시드 넣기]: 리포 JSON → Supabase 업서트 (기존 수정분 보존/덮어쓰기 선택)
- 저장 → Firestore `wed100_questions` 갱신 → ISR 재검증(1시간) 반영

### 3.4 대시보드 (/admin/dashboard)
- KPI: 조회수·재생수·완청률·상담 CTA 클릭 (기간 7/30/90일)
- 가장 많이 본 질문 TOP 10 · 파트별 소비 비중 · 콘텐츠 제작 커버리지(본문/음성/영문자막/큐)

## 4. 데이터 및 기술 설계

### 4.1 스택
기존 사이트 그대로: **Next.js 16 (App Router) + Tailwind v4 + shadcn/ui + Firebase(Firestore) + Vercel**

### 4.2 데이터 흐름
```
원고 docx ──1_parse_docx.py──▶ src/data/wed100.json (시드)
                                    │
                 2_gen_images.py ──▶ public/wed100/img/*.svg (210장)
                 3_gen_tts.py ─────▶ public/wed100/audio/*.mp3 + *.vtt
                                    │            (JSON에 타임코드 기록)
                                    ▼
             [DB에 시드 넣기] ──▶ Firestore wed100_questions  ←─ 어드민 편집
                                    │
                          사이트: DB 우선, 실패 시 시드 JSON 폴백
```
- **시드 JSON 폴백** 덕분에 Firebase 세팅 전에도 사이트 전체가 동작
- 이벤트: `wed100_events` 컬렉션 — 플레이어에서 자동 적재

### 4.3 데이터 모델 (Firestore, firebase/firestore.rules)
- `wed100_questions/{slug}`: id, slug, part, partTitle, n, question(_en), answer[], cues[](i/ko/en/start/end), keywords, questionAudio, audio, duration, heroImage, thumbImage, published, updatedAt
- `wed100_events/{auto}`: slug, event(view/play/complete/cta_click), lang, createdAt
- 기존 기능: `bookings`, `reviews`, `gallery_images` 컬렉션 (전부 Firestore로 통일)

### 4.4 TTS 파이프라인 (edge-tts)
- 진행자 질문: `ko-KR-InJoonNeural` / 원장 답변: `ko-KR-SunHiNeural` (-4% 속도, 중년 청취 배려)
- **문장 단위 합성 → 길이 실측 → 결합** 방식이라 자막 타임코드가 문장 경계와 정확히 일치
- 산출: mp3(모노 48k) + ko.vtt + en.vtt + JSON 타임코드
- 수정 시 `python3 scripts/wed100/3_gen_tts.py {slug} --force` 로 해당 문항만 재생성
- 총 105문 ≈ 2시간 분량, 약 55MB

### 4.5 이미지 전략
- 기본: 자동 생성 SVG (질문당 hero 16:9 + thumb 1:1, 파트 테마 컬러·모티프, 저작권 안전)
- 어드민에서 **사진 URL로 교체 가능** (Firebase Storage 업로드 → URL 입력). 비우면 SVG 복귀
- 권장 로드맵: 대표 질문 20~30개부터 실제 시술 사진으로 교체

### 4.6 SEO
- 질문 1개 = 정적 페이지 1개 (SSG + ISR 1h), 제목·설명·OG 이미지 자동
- FAQPage JSON-LD 구조화 데이터 → 검색 결과 리치 스니펫
- 검색 키워드 축: "혼주메이크업 (비용|예약|올림머리|한복|전문점|출장)" 등 105개 롱테일

## 5. 다국어 전략 (이번: 한국어 콘텐츠 + 한/영 자막)
- 1단계(현재): 콘텐츠 한국어, 자막 한/영 토글 — 데이터 구조는 cue 단위 `{ko, en}` 으로 언어 확장 가능
- 2단계: 질문·본문 영어 페이지(`/en/wed100`), 영어 TTS(예: en-US Aria) — cues에 `en` 이미 존재하므로 음성만 추가
- 3단계: 중국어·일본어 자막 (`cues[].zh/ja` 필드 추가) — 국제결혼 가정 타깃

## 6. 운영 시나리오
1. 원장: 어드민에서 오타·가격·정책 수정 → 저장 (즉시 DB, 페이지는 1시간 내 반영)
2. 본문을 크게 고친 경우: [큐 재생성] → 로컬에서 TTS 재생성 스크립트 실행 → 오디오 교체
3. 사진 확보 시: Storage 업로드 → 어드민에서 URL 교체
4. 월 1회 대시보드 확인 → TOP 질문을 블로그·인스타 콘텐츠로 재활용
