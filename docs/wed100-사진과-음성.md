# wed100 — 사진 배정과 MC 음성

## 1. 사진

### 폴더에 넣고 스크립트 두 번

```bash
# 1) 사진 → hero/thumb 생성 + 카탈로그 갱신
python3 scripts/wed100/4_build_photos.py --src ~/Claude/Projects/makeupforl/photos

# 2) 107문에 자동 배정
python3 scripts/wed100/5_assign_photos.py

# 운영 DB 까지 한 번에
GOOGLE_APPLICATION_CREDENTIALS=<서비스계정.json> \
  python3 scripts/wed100/5_assign_photos.py --firestore
```

새 사진만 처리하고 이미 만든 것은 건너뜁니다. 다시 만들려면 `--force`.

### 사진 폴더 규칙

하위 폴더 이름이 곧 분류입니다. 분류가 파트 배정을 결정합니다.

```
photos/
  인물/   완성컷 (얼굴 노출)   → PART 0·1·2·3·6·7
  헤어/   올림머리·쪽머리       → PART 4·6
  한복/   저고리·노리개 디테일   → PART 5
```

하위 폴더 없이 넣으면 전부 `인물`로 잡힙니다. `src/data/wed100-photos.json` 에서
`cat` 만 고치면 되고, `catLocked: true` 인 항목은 다시 돌려도 유지됩니다.

### 크롭

- **hero 1600×900** — 가로 사진은 기준점 중심으로 잘라내고, 세로 사진은 얼굴이
  잘리므로 같은 사진을 흐리게 깐 배경 위에 원본을 통째로 얹습니다.
- **thumb 800×800** — 기준점 중심 정사각 크롭.
- 기준점(`focus`)은 OpenCV 얼굴 검출로 자동으로 잡고, 손으로 고친 값은
  `focusLocked: true` 로 지켜집니다. `--refocus` 는 잠기지 않은 것만 다시 잡습니다.

### 문항별로 사진을 직접 고르기

어드민 `/admin/wed100` → 문항 선택 → **대표 이미지** → 사진 클릭.
고르는 순간 그 문항은 `photoAuto: false` 가 되어 **자동 배정이 다시 돌아도 유지**됩니다.
되돌리려면 [자동 배정으로] 를 누르고 저장한 뒤 `5_assign_photos.py` 를 다시 실행하세요.

### 자동 배정 규칙

파트별 사진 풀에서 순서대로 돌려 씁니다(`PART_CATS` in `5_assign_photos.py`).
사진이 늘면 배정이 다시 섞이는 것이 정상입니다. 고정하고 싶은 문항은 어드민에서
직접 지정하세요.

## 2. MC(진행자) 음성 — Typecast

### 왜 Typecast 인가

edge-tts 가 무료로 열어 주는 **한국어 여성 음성은 `ko-KR-SunHiNeural` 하나뿐**입니다.
그래서 이전에는 MC 와 원장님이 같은 음성을 피치·속도만 바꿔 쓰고 있었습니다.
Azure 에 있는 다른 한국어 여성 음성(JiMin·SeoHyeon·SoonBok·YuJin)은 무료
엔드포인트에서 거부됩니다.

지금 구성:

| 화자 | 엔진 | 음성 |
|---|---|---|
| 진행자(질문) | Typecast `ssfm-v30` | **Jinhee** `tc_6731b2b2478a48710ecc9158` (아나운서 톤) |
| 원장님(답변) | edge-tts | `ko-KR-SunHiNeural` `+25%` `-6Hz` (1.25배속) |

### 환경변수

```
TYPECAST_API_KEY=...            # 필수. 없으면 MC 도 edge-tts SunHi 로 폴백
TYPECAST_VOICE_ID=tc_6731b2b2478a48710ecc9158   # 선택 — 다른 음성으로 교체할 때
TYPECAST_MODEL=ssfm-v30
TYPECAST_EMOTION=normal         # normal|happy|sad|angry|whisper|toneup|tonedown
```

- 벌크 생성(`scripts/wed100/3_gen_tts.py`) — 로컬 셸 환경변수
- 어드민 [음성 재생성](`/api/wed100/tts`) — **Vercel 환경변수에 등록해야** 동작합니다.
  등록 전까지는 어드민에서 재생성한 문항만 예전 SunHi 목소리로 나옵니다.

### 규격을 맞추는 이유

Typecast 는 44.1kHz WAV, edge-tts 는 24kHz/48kbps mp3 로 줍니다. 그대로 이어붙이면
재생 길이와 자막 타임코드가 어긋나므로 **양쪽 다 24kHz / 48kbps CBR / 모노 mp3** 로
맞춥니다. 서버(`src/lib/tts/typecast.ts`)는 ffmpeg 이 없어 WAV 를 직접 파싱해
선형 보간으로 리샘플링한 뒤 lamejs 로 인코딩합니다. 1초 = 6000바이트라
바이트 길이만으로 타임코드를 정확히 계산할 수 있습니다.

두 엔진의 음량은 측정 결과 둘 다 약 −17.8 LUFS 로 이미 맞아, 별도 정규화는 하지 않습니다.

### 음성 바꾸기

```bash
# 여성 음성 목록
curl -s -H "X-API-KEY: $TYPECAST_API_KEY" \
  "https://api.typecast.ai/v2/voices?model=ssfm-v30&gender=female" | jq '.[].voice_name'

# 전체 재생성
TYPECAST_API_KEY=... TYPECAST_VOICE_ID=tc_... \
  python3 scripts/wed100/3_gen_tts.py --force
```

재생성하면 자막 타임코드도 같이 다시 계산됩니다.
