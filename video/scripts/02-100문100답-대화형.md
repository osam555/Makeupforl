# 02 · 혼주메이크업 100문 100답 — 두 사람 대화형 (혼주 × 김성희 대표)

- 원장님 대본(01)을 **처음 혼주가 되는 어머니가 묻고 원장님이 답하는** 대화로 옮긴 것.
  100문100답 자체가 「진행자가 묻고 원장님이 답하는」 형식이라 상품 소개와 결이 같다.
- 등장인물은 **딱 두 명, 끝까지 같은 사람**. 질문마다 다른 혼주를 쓰지 않는다(2026-10-15 결정 —
  HeyGen·Flow 가 실패한 이유가 얼굴·목소리가 바뀌는 것이었다).
- 한 화면에 한 사람(`book/promo/영상제작-규칙.md` 1절) — 묻는 컷과 답하는 컷을 번갈아 자른다.
- 예상 길이 약 40~45초.

## 인물 고정표

| | 원장 김성희 | 혼주(어머니) |
|---|---|---|
| 얼굴 | `video/work/ref-face.png` 한 장 | 레퍼런스 한 장을 정해 고정(아래 「남은 일」) |
| 옷·머리 | 검정 핀스트라이프 재킷 + 흰 이너, 짧은 검정 머리, 안경 없음 | 베이지/크림 상의, 단정한 단발, 진주 귀걸이, 안경 없음 |
| 배경 | 밝은 웨딩홀(촛대 벽등) | 따뜻한 거실 또는 같은 웨딩홀의 다른 자리 |
| 목소리 | 채널 영상에서 복제한 원장님 목소리(`scripts/video/clone_tts.py`) | 고정 음성 하나 — 100문100답 진행자와 같은 Typecast 「Jinhee」 또는 다른 고정 음성 |
