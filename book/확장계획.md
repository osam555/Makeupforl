# 『혼주메이크업 100문 100답』 단행본 확장 계획 (확정)

- 판형: 신국판(152×225mm) / **총 214쪽**
- 조판: **표준 신국판 30자 × 26행 = 780자/쪽**
- 반페이지 이미지 **30장** 포함
- 구성: **100문100답 형식 유지** — 별도 칼럼·에세이 없이 답변 안에서만 확장
- 확장 방식: `목표자수 = max(현재자수, 1000)`
- 문체: 기존 존댓말 상담체 유지
- 근거: `md-honjoo/` 네이버 블로그 `makeupstar77` 1,166편

## 2. 문항별 목표 자수

```
목표자수 = max(현재자수, 1000)
```

- 1,000자 이상 **4개 문항만 원문 그대로** (prologue 1,087 / p1-03 1,213 / 7번 1,044 / 87번 1,037)
- 나머지 98개를 1,000자까지 상향 (문항당 평균 **+537자**)
- 총 추가 집필 **52,583자** (49,798 → 102,381)

> 표준 조판에서는 "상위 분량 유지"가 성립하지 않는다. 200~210쪽에 필요한 하한이
> 907~975자라, 현재 900자를 넘는 문항이 8개뿐이기 때문이다. 1,000자 하한은
> 이 제약 아래에서 집필하기 가장 편한 기준치다.
